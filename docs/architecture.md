# BhoomiChain Architecture & Technical Design

## 1. Executive Summary
BhoomiChain is a hybrid decentralized land registration and title governance platform designed to provide mathematical tamper-evidence, unalterable historical provenance, and multi-party cryptographic authorization for real-estate conveyance.

## 3. High-Level Flow
1. **User Authentication**: Email/password credentials generate a standard JWT session. To interact with high-trust features, the user links an Ethereum wallet by signing a dynamic 32-byte challenge nonce generated by the backend.
2. **Land Registration Submission**: The land owner inputs cadastral parameters (survey number, boundaries, acreage, jurisdiction) and pinpoints GPS coordinates using an interactive Leaflet map.
3. **Deterministic Document Fingerprinting**: Attached deed PDFs are deterministically hashed using SHA-256 both client-side and server-side:
   $$\text{documentHash} = \text{SHA-256}(\text{file\_buffer})$$
4. **Sub-Registrar Inspection**: Authorized government officials inspect submitted deeds, cross-reference revenue records, and perform cryptographic integrity checks.
5. **On-Chain Commitment**: Upon approval, the backend interacts with `LandRegistry.sol` using the registrar's authorized private key to execute `registerLand(...)`.
6. **State Reconciliation & Audit Log**: Emitted on-chain events (`LandRegistered`, `OwnershipTransferred`) are decoded. The transaction hash, block number, and contract address are permanently indexed into PostgreSQL, creating an unshakeable audit trail.
7. **Multi-Party Conveyance**: Title transfer requires agreement from the seller, prospective buyer, and government registrar. When approved, ownership is reassigned on the smart contract, appending a new block to the immutable chain-of-custody.
